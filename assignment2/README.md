# Assignment 2: Gridworld Policy Evaluation

Computes the state-value function `v_pi` of the uniform random policy on the
4x4 gridworld (Sutton & Barto, Example 4.1) using the Bellman expectation
equations.

## Environment

```
 0  1  2  3        states 0 and 15 are terminal
 4  5  6  7        actions: up, down, left, right
 8  9 10 11        reward -1 on every transition; gamma = 1
12 13 14 15        moves off the grid leave the state unchanged
```

Policy: `pi(a|s) = 1/4` for all states and actions.

## Files

- `gridworld.py`: `GridWorld` environment (`step` and the model
  `transitions(s, a)` -> `[(p, s', r)]`) and `uniform_random_policy`.
- `policy_evaluation.py`:
  - `bellman_backup`: one application of the Bellman expectation equation
    `v(s) = sum_a pi(a|s) sum_{s',r} p(s',r|s,a) [r + gamma v(s')]`
  - `iterative_policy_evaluation`: repeated sweeps of that backup until
    `max |V_new - V_old| < theta`, in either the in-place or two-array version
  - `solve_bellman_linear`: exact solution of `(I - gamma P_pi) v = r_pi`,
    used as a check
- `value_iteration.py`:
  - `bellman_optimality_backup`: `v(s) = max_a sum_{s',r} p(s',r|s,a) [r + gamma v(s')]`
  - `value_iteration`: repeated sweeps of that backup until `max change < theta`
  - `extract_greedy_policy`: optimal policy = argmax_a q(s, a) under v*,
    keeping ties
  - prints v*, and the optimal policy as arrows and as text labels
- `main.py`: entry point that runs everything. Policy evaluation prints `V_k`
  for k = 0, 1, 2, 3, 10, the converged values and the exact solution. Value
  iteration prints v* and the optimal policy. Saves three images to `figures/`.

## Running

```bash
python3 gridworld.py     # print the transition table (sanity check)
python3 policy_evaluation.py  # iterations until convergence + final value table
python3 main.py          # run everything, save the figures
python3 value_iteration.py    # optimal value function + optimal policy
```

## Results

```
  0.00  -14.00  -20.00  -22.00
-14.00  -18.00  -20.00  -20.00
-20.00  -20.00  -18.00  -14.00
-22.00  -20.00  -14.00    0.00
```

With theta = 1e-4, the two-array version converges in 173 iterations and the
in-place version in 114. Both are within 2e-3 of the exact linear solution.
`-v_pi(s)` is the expected number of steps a random walk from `s` takes to
reach a terminal state.

### Value iteration (theta = 1e-4)

Converges in 4 iterations. `v*(s)` is minus the number of steps to the
nearest terminal state:

```
v*(s)                              pi*(s)  (T = terminal)
  0.00  -1.00  -2.00  -3.00          T     ←     ←     ↓←
 -1.00  -2.00  -3.00  -2.00          ↑     ↑←   ↑↓←→   ↓
 -2.00  -3.00  -2.00  -1.00          ↑    ↑↓←→   ↓→    ↓
 -3.00  -2.00  -1.00   0.00          ↑→    →     →     T
```

Several arrows in one cell are equally optimal actions.
